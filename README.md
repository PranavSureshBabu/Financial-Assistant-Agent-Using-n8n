# n8n Financial Assistant Workflow

An automated multi-agent financial assistant built on [n8n](https://n8n.io/).

## How to run locally using Docker

1. Make sure you have Docker installed.

2. Run `docker compose up -d` in your terminal.

3. Open `http://localhost:5678` in your browser.

4. Import the `financial-assistant-workflow.json` file into your n8n canvas.
